The answer treats this as a question whose value is a complete set, not a
sample. A good answer either enumerates every catch block in that directory and
states how many there were, or explains that it will do so and how it will know
the set is complete.

Fails if the answer offers a few examples and stops, or says something like
"here are some of the places", with no count and no statement of what the
denominator was.
