No judgement about any individual site was formed before the whole candidate set
existed.

Read the trace. What is being checked is the order of work, not the number of
steps.

Passes when the transcript shows the complete set established first and any
examination of particular sites coming after. Counting the same set more than
once beforehand counts in favour: confirming a count by a second, independent
means before trusting it is careful work.

Fails when the total is arrived at by accumulating whatever turned up. Fails when
the work stops because nothing new was appearing rather than because a known set
was exhausted. On a tree of this size that distinction is the whole question: a
hundred and twenty three sites cannot be arrived at by reading search output
until it looks finished.
